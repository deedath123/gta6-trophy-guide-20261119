Leonida Trophy Guide & Tracker — the best offline guide to all 55 Grand Theft Auto VI trophies on PlayStation 5: 1 platinum, 2 gold, 6 silver, 46 bronze. Every trophy shows its official name, description and grade exactly as PlayStation publishes it, plus a guide in our own words that cites its sources (Push Square, PowerPyx, WikiGTAVI, PSNProfiles / Exophase). The tracker saves progress in the browser, exports and imports it, filters by story, missable, collectibles, activities and online, and hides story spoilers until earned. The roadmap orders the platinum hunt into story-chapter play sessions, and the Platinum Path planner always shows what is next. One trophy may be missable — Positive Mental Attitude, with a Chapter 1 meditation — and it is flagged everywhere it matters. No online trophies. No Rockstar artwork. Works fully offline.

## Run it

Serve `app/` with any static server and open `index.html` in desktop Chrome:

```sh
cd app && python3 -m http.server 8080
```

Then open http://localhost:8080 — no build step, no network needed. Tick trophies to save progress (localStorage), use Export / Import to move it between browsers, and switch between the paper-light and night-dark themes.
